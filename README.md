# AI in Drug Discovery

This repo contains computer labs for the AI in Drug Discovery module at the University of Nottingham.

This repo contains code taken or adapted from the following sources:

- https://github.com/gmum/mldd26
- https://www.kaggle.com/learn/intro-to-machine-learning
- https://shap.readthedocs.io/en/latest/
